# NEODOKU: Absolute Logic Engine

**NEODOKU** — это не просто судоку. Это киберпанк-платформа для когнитивной тренировки мозга, использующая принципы синестезии, строгую валидацию логики и соревновательные механики. 

> **Проект разработан в рамках выполнения Технического Задания для 2 этапа отбора в nFactorial Incubator 2026.**

🔗 **[Live Demo (Vercel)](https://neodoku.vercel.app)**  
🔗 **[API Swagger Docs (Render)](https://neodoku-api.onrender.com/docs)**

---

## Ключевые фичи (Level 4)

### 1. Fullstack Architecture & Security
- Реальная система регистрации и авторизации.
- Пароли не хранятся в открытом виде (используется хеширование `bcrypt` через `passlib`).
- База данных SQLite для хранения профилей операторов.

### 2. Synesthesia UI (Когнитивный дизайн)
- Отказ от скучных черно-белых цифр. Каждая цифра имеет свой уникальный неоновый цвет.
- Это тренирует ассоциативные связи мозга ("Цвет-Символ") и ускоряет паттерн-матчинг игрока.
- Глобальный Canvas-фон с использованием алгоритма **Poisson Disk Sampling** для плавной генерации частиц.

### 3. AI Logic Assistant
- Бэкенд не просто выдает ответ. API генерирует текстовые подсказки, объясняя логику решения (например: *"By elimination in the 3x3 quadrant, 7 is the only logical fit"*).

### 4. Отказоустойчивость (Graceful Degradation)
- Если бэкенд недоступен (например, холодный старт сервера), фронтенд не падает.
- Автоматически активируется **Local Emergency Protocol** — загружается резервная матрица судоку, чтобы пользователь мог продолжить игру без задержек.

### 5. Бизнес-логика и Монетизация
- Внедрен **Daily Cognitive Challenge** (ежедневная матрица, генерируемая через единый Seed на сервере — каждый день новая, но одинаковая для всех игроков в мире).
- Модальное окно **PRO Upgrade** (конвертация пользователей в платящих за счет расширенной аналитики и продвинутого AI-тренера).

## Важная информация для судей (Прочтите перед тестом)

1. **Холодный старт (Cold Start):** Бэкенд развернут на бесплатном тарифе *Render.com*. Если сервер спал, **первая попытка авторизации или регистрации может занять от 30 до 50 секунд**. Пожалуйста, дождитесь ответа сервера (на кнопке будет крутиться лоадер).
2. **База данных:** В текущей версии для скорости разработки используется SQLite. Файловая система Render эфемерна, поэтому после перезагрузки сервера (раз в сутки) аккаунты могут сбрасываться. Архитектура проекта полностью готова к миграции на PostgreSQL в продакшене.
